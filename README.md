# Graziano Guiducci

AI systems architect and independent researcher in Italy. I develop MAIOS and
work on how AI systems can understand a changing situation, act through the
competences it calls for, and let what they learn change their next work.

## MAIOS Project Kernel

[MAIOS Project Kernel](https://github.com/GrazianoGuiducci/maios-project-kernel)
brings an AI agent an evolving operating kernel: knowledge and methods for
understanding the present, doing useful work, forming competences and
continuing from what it learns.

Work can produce both a result and a reusable ability. The Kernel keeps the
reasons behind a decision with the work it belongs to, and returns a useful
method to the competence that should use it next. Its activity can reform its
knowledge, competences and organization.

You can begin by studying the public source with your own agent. Installation
is another available path when you want to use the Kernel in your context.

- [Study the Kernel with your agent](https://github.com/GrazianoGuiducci/maios-project-kernel#study-contribute-or-build)
- [Install and start from your context](https://github.com/GrazianoGuiducci/maios-project-kernel#start-from-your-context)
- [Explore the source knowledge](https://github.com/GrazianoGuiducci/maios-project-kernel/blob/main/knowledge/KERNEL.md)

## Research

[System Semantic Kernel (SSK)](https://github.com/GrazianoGuiducci/maios-ssk-paper)
is the public working-paper corpus for the relation among meaning, sources,
situated competence, action and consequence in agentic systems. It develops
the conceptual research. The software product is developed in the MAIOS
Project Kernel repository.
